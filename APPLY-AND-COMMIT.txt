FULL REPOSITORY SNAPSHOT — COPY .git, THEN COMMIT

This ZIP contains the complete repository working tree at its archive root. It intentionally does not contain .git/.

1. Extract the ZIP into a new folder (for example, Levi-icon-ready/).
2. Copy the entire .git directory from your existing Levi-icon clone into that extracted folder, next to README.md and index.html. Do not copy individual files from the ZIP into the old clone.
3. Open a terminal in the extracted folder and run:

   git status --short
   git branch --show-current
   git add -A
   git commit -m "Unify icon gallery and refine project identity previews"
   git push origin HEAD

The .git directory must be the complete directory from a normal clone, not a .git file or a partial copy. The extracted working tree already contains the V1/V2 galleries, source assets, derived exports, documentation and Pages workflow.

There is no icon.png anywhere in this snapshot. Project masters use icon.svg; PNG outputs are specifically named favicon-*.png, apple-touch-icon.png and og-image.png.
